# Matrice Booking — L'ArtBoristerie

Outil de booking et de production qui remplace l'espace Notion : contacts et structures, booking avec carte et trajets, production (suivi admin, facturation, commissions), ticketing, communication, projets, prospection et To Do.

- `index.html` — l'application (publiée via GitHub Pages).
- `supabase/schema.sql` — structure de la base Supabase (projet « Lartbo-matrice »).
- `supabase/import_notion.sql` — import des données Notion, exécuté dans Supabase.
- `apps-script/Code.gs` — création automatique des dossiers de production Drive à la confirmation d'une date.
- `apps-script/Import.gs` — variante de l'import Notion via Apps Script (non utilisée).
